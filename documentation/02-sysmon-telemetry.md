# Module 02: Sysmon Telemetry & Endpoint Monitoring

## 1. Overview
Deploying Microsoft Sysmon (System Monitor) across the Domain Controller and Windows client endpoint to capture granular, low-level system activity and process execution logs for threat detection.

## 2. Objectives
* Install and configure Sysmon using an industry-standard configuration (SwiftOnSecurity).
* Capture key endpoint telemetry: Process Creation (Event ID 1), Network Connections (Event ID 3), and File Creation Time changes (Event ID 2).
* Prepare endpoints for central log forwarding to a SIEM.
